`GET /api/v1/private/position/position_mode`. The recognized causes are
HTTP 401/403/429/5xx, timeout/network, and bounded MEXC numeric errors.

message is printed. Any classified failure still produces the SAME critical
outbox status and sticky latch. All unrelated MEXC GETs preserve original
generic error handling.
