MEXC Exhaustion Scanner v0.9.3

Discord routing:
- DISCORD_WEBHOOK_URL = existing confirmed-short alerts webhook
- DISCORD_PERFORMANCE_WEBHOOK_URL = NEW webhook for the performance/stats Discord server or channel

Render steps:
1. Deploy these files.
2. In the worker's Environment settings, add DISCORD_PERFORMANCE_WEBHOOK_URL with the webhook URL created in the stats Discord channel.
3. Keep DISCORD_WEBHOOK_URL unchanged for confirmed-short alerts.
4. Redeploy/restart the worker.
5. Test the new stats board from Render Shell:
   python -m app.report_now

No migration is required. Keep migrations 001 through 008 unchanged.
If DISCORD_PERFORMANCE_WEBHOOK_URL is omitted, reports fall back to DISCORD_WEBHOOK_URL for backward compatibility.
